# Sumen — Growth OS v2.0
AI Growth Transformation Platform — Internal Team Software

## Deploy in 15 minutes

### Step 1 — Put code on GitHub
1. Go to github.com → Create free account → New repository → name it `sumen-growth-os`
2. Drag and drop this unzipped folder into the repository
3. Click "Commit changes"

### Step 2 — Deploy to Vercel (free)
1. Go to vercel.com → Sign in with GitHub
2. Click "Add New Project" → Select `sumen-growth-os`
3. Click "Deploy" — auto-detects Next.js
4. Your URL: `sumen-growth-os.vercel.app`

### Step 3 — Share with team
Send the Vercel URL. Bookmark it. Done.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## What's inside
- Multi-client workspace (add unlimited clients with + button)
- All data saves to browser localStorage automatically
- Module 1: Research (ICP, personas, brand, what worked, competitors, offers)
- Module 2: Attribution (tracking, KPIs, channel breakdown)
- Module 3: CRO (full checklist for every page, funnel analysis, Hotjar)
- Module 4: Creative (creatives tracker, angles, hooks, scripts, strategy)
- Module 5: Paid Ads (budget allocation, platforms, campaigns, copy, scaling rules)
- Module 6: Retention (Klaviyo flows, segments, SMS, referral program)
